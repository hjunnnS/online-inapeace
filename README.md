# In a Peace · 바릴로체

PC 웹 시제품. 바릴로체 대성당 본당 일부를 걸으며 앉아 쉬고, 가상 개인실에서 글을 내려놓을 수 있다. 현재 M8에는 성탄 트리, 캐럴 10곡, 가상 신자 20명(미사포10명)과 상세 색유리가 포함된다.

## 실행

Node.js 24에서 `npm ci` 후 `npm run dev`. `npm run build`는 TypeScript 검사와 정적 배포 파일 생성을 수행한다. `npm run assets`로 장면 GLB 3개를 재생성할 수 있다.

입장 후 WASD·방향키·바닥 클릭으로 이동한다. 드래그와 휠로 시점을 조절한다. 앉기 버튼으로 좌석에 접근하고, 고해소 버튼으로 출입 지점까지 이동한다. 개인실에서 글을 내려놓거나 취소하면 본당으로 복귀한다. 음악 메뉴에서 캐럴 재생·다음 곡·음량과 출처를 확인한다.

## 자산과 데이터

- 바릴로체 GLB와 검증용 임시 공간 GLB 두 개는 이 프로젝트에서 생성했다. 석재의 색, 네오고딕 아치, 색유리, 좌석과 제대 축을 [성당 역사 안내](https://iglesiacatedralbariloche.com/catedral.html), [사진 갤러리](https://iglesiacatedralbariloche.com/fotos.html), [색유리 해설](https://iglesiacatedralbariloche.com/vitrales.html)에 대조한 부분 재구성이다. 치수·배치·창 문양을 단순화했고 고해소 개인실은 창작 부속 공간이다. 외부 사진·스캔은 번들에 포함하지 않았다. M8의 색유리는 별도로 생성한 창작 이미지다.
- 전례 문구 낭독과 해당 음성 파일은 M8에서 제거했다. 캐럴 녹음의 원저작자·라이선스·변경 사항은 `docs/carol-credits.md`와 음악 패널에 표시한다.
- 고해소 글은 현재 페이지의 편집기에만 있다. 완료·취소·Escape·페이지 이탈/복원 때 지운다. 음악 및 장면 파일은 정적 요청이며 글 본문을 요청에 넣지 않는다.

## 검수 상태

기술 검수는 최종 빌드에서 Chrome과 WebKit으로 진행했다. 3~5명 분위기 관찰, M1 기준 Windows/Iris Xe 실측은 검수 항목으로 남아 있다. 관련 이슈는 [음원 #22](https://github.com/hjunnnS/online-inapeace/issues/22)와 [통합 검수 #29](https://github.com/hjunnnS/online-inapeace/issues/29)다.

## M3 성당 컬렉션

성당 둘러보기에서 열 곳의 이름·도시·미리보기·참고 자료를 볼 수 있다. 목록의 미리보기는 같은 GLB를 브라우저에서 렌더링해 캡처했다. 바릴로체 외 아홉 곳은 공식 건축 자료를 참고한 창작 부분 재구성으로 치수, 문양, 조각과 세부 배치를 단순화했다. 자료 사진은 번들에 포함하지 않는다. 장면별 출처는 src/cathedrals.json, 제작 방식은 scripts/collection.mjs에 있다. 장면은 기존 로더와 이동·착석·고해소·오디오를 공유한다. 첫 입장은 방문자 계정 없이 동작한다.

## M6·M7 바릴로체 체험

바릴로체에서 미사포를 쓰고 촛불을 집어 들고 걷거나 앉은 뒤 촛대에 놓을 수 있다. 가까운 의자·촛대·고해소의 안내 버튼도 사용할 수 있다. 조명 메뉴에서 색유리 빛과 낮·해질녘·밤을 바꾸고 움직임과 효과를 줄일 수 있다. 고해소의 글은 바로 지워지며 추상적인 입자와 상승 시점으로 마무리한다. Esc로 연출을 건너뛸 수 있다.

성가대 버튼으로 제대 앞에 가서 감상하거나 66초 지휘 체험을 시작한다. 방향키 또는 화면 버튼을 음표에 맞춰 누른다. 본당의 가상 신자 스무 명은 열두 명이 앉고 여덟 명이 서 있으며 실제 접속자를 나타내지 않는다. 묵주는 아래로 당기거나 버튼·키보드로 한 알씩 넘긴다. 기념사진에서 현재 구도·정면 구도를 선택해 900×1100 PNG를 저장한다.

성가대의 「고요한 빛」은 이 프로젝트에서 제작한 합성 모음 합창이며 실제 성가대 녹음이 아니다. `python3 scripts/choir-audio.py`로 합창과 행동 효과음을 재생성한다. Python 표준 라이브러리와 ffmpeg가 필요하다. 레이스·석재·목재·빛 질감도 `src/sanctuary.ts`에서 직접 그린다. M8은 이전 오르간 배경음을 캐럴 녹음으로 교체했다.

`npm test`는 지휘 판정·재시작 및 촛불 스프라이트 자산 해제 회귀 테스트를 실행한다. M6·M7의 기능 확인 결과와 사람의 청취·분위기 평가 범위는 `docs/M6-verification.md`, `docs/M7-verification.md`에 기록했다.

## M8 성탄 분위기와 상세 색유리

바릴로체 뒤편 왼쪽에 높이 약 7m의 트리를 배치했다. 관람 지점의 「뒤편 크리스마스 트리」를 선택해 가까이 걸어갈 수 있다. 캐럴은 열 곡을 한 번씩 섞어 재생하며 순환 경계에서도 같은 곡을 연달아 고르지 않는다. 고해소·성가대 공연·페이지 비활성화 중에는 일시 정지한다. 개별 곡을 불러오지 못하면 다음 곡으로 넘기고, 모두 실패하면 재시도 안내를 표시한다.

색유리 창 15개(양측 12개·제대 뒤 3개)에 세 가지 창작 문양을 적용했다. 같은 창 이미지로 바닥 색빛을 만들고, 부드러운 빛줄기와 미세 먼지를 더했다. 낮·해질녘·밤에 강도를 바꾸며 밤에는 햇빛을 끈다. 움직임 줄이기는 먼지·트리·인물의 움직임을 멈춘다. 창작 이미지와 구현 방식은 `docs/stained-glass.md`, 검수는 `docs/M8-verification.md`를 참고한다. 이 변경은 바릴로체 체험에 적용되며 다른 아홉 성당의 건축을 일괄 수정하지 않는다.

## M9 신자와 빛 조정

가상 신자는20명이며 절반인10명이 미사포를 쓴다. 기존 빈 좌석 선택은 유지한다. 트리 전구100개에는 개별 밝기 변화와 후광을 적용하고, 본당 양쪽 벽기둥의 촛대12곳에 불꽃과 후광을 더했다. 움직임 줄이기에서는 일정한 밝기로 유지한다. 색유리는 원본 이미지를 수정하지 않고 렌더링 단계에서 채도를22% 줄이고 밝은 유리색을 약5.5% 섞었다. 짙은 납선은 보존하며 바닥 색빛에도 같은 보정을 적용한다.
