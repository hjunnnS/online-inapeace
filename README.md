# In a Peace · 바릴로체

PC 웹 시제품. 바릴로체 대성당 본당 일부를 걸으며 앉아 쉬고, 가상 개인실에서 글을 내려놓을 수 있다. 현재 M16은10개 성당의 촛불·착석·개인 기도·마음 털어놓기·사진·조명을 공통 제공한다. 바릴로체에는 성탄 트리, 캐럴10곡, 가상 신자20명과 오가는 방문자3명, 성가대와 집전 장면을 더했다. 아래 M단계 설명은 변경 이력이다.

## 기술 문서와 공개 운영 일정

[아키텍처·개발 언어 문서](docs/architecture.md)에 현재 모듈, 3D·오디오·데이터 흐름, 실행·배포 구조를 정리했다. 스탠드얼론 전환은 취소했다. 공개 테스트는 2026-11-06까지 유지하고, 2026-11-07 00:00 한국 시간부터 소유자 전용으로 전환하도록 클라우드 작업을 예약했다. 실제 종료 확인은 [#90](https://github.com/hjunnnS/online-inapeace/issues/90)에서 추적한다.

## 실행

Node.js 24에서 `npm ci` 후 `npm run dev`. `npm run build`는 TypeScript 검사와 정적 배포 파일 생성을 수행한다. `npm run assets`로 성당10개와 검증용 임시 공간2개의 GLB를 재생성할 수 있다.

입장 후 WASD·방향키·바닥 클릭으로 이동한다. 드래그와 휠로 시점을 조절한다. 앉기 버튼으로 좌석에 접근하고, 고해소 버튼으로 출입 지점까지 이동한다. 개인실에서 글을 내려놓거나 취소하면 본당으로 복귀한다. 음악 메뉴에서 캐럴 재생·다음 곡·음량과 출처를 확인한다.

## 자산과 데이터

- 바릴로체 GLB와 검증용 임시 공간 GLB 두 개는 이 프로젝트에서 생성했다. 석재의 색, 네오고딕 아치, 색유리, 좌석과 제대 축을 [성당 역사 안내](https://iglesiacatedralbariloche.com/catedral.html), [사진 갤러리](https://iglesiacatedralbariloche.com/fotos.html), [색유리 해설](https://iglesiacatedralbariloche.com/vitrales.html)에 대조한 부분 재구성이다. 치수·배치·창 문양을 단순화했고 고해소 개인실은 창작 부속 공간이다. 외부 사진·스캔은 번들에 포함하지 않았다. M8의 색유리는 별도로 생성한 창작 이미지다.
- 전례 문구 낭독과 해당 음성 파일은 M8에서 제거했다. 캐럴 녹음의 원저작자·라이선스·변경 사항은 `docs/carol-credits.md`와 음악 패널에 표시한다.
- 고해소 글은 현재 페이지의 편집기에만 있다. 완료·취소·Escape·페이지 이탈/복원 때 지운다. 음악 및 장면 파일은 정적 요청이며 글 본문을 요청에 넣지 않는다.

## 검수 상태

이전 단계에는 Chrome과 WebKit 검수 기록이 있다. M14의 현재 검수 범위와 한계는 `docs/M14-verification.md`에 별도로 기록했다. 3~5명 분위기 관찰, M1 기준 Windows/Iris Xe 실측은 검수 항목으로 남아 있다. 관련 이슈는 [음원 #22](https://github.com/hjunnnS/online-inapeace/issues/22)와 [통합 검수 #29](https://github.com/hjunnnS/online-inapeace/issues/29)다.

## M3 성당 컬렉션

성당 둘러보기에서 열 곳의 이름·도시·미리보기·참고 자료를 볼 수 있다. 목록의 미리보기는 같은 GLB를 브라우저에서 렌더링해 캡처했다. 바릴로체 외 아홉 곳은 공식 건축 자료를 참고한 창작 부분 재구성으로 치수, 문양, 조각과 세부 배치를 단순화했다. 자료 사진은 번들에 포함하지 않는다. 장면별 출처는 src/cathedrals.json, 제작 방식은 scripts/collection.mjs에 있다. 장면은 기존 로더와 이동·착석·고해소·오디오를 공유한다. 첫 입장은 방문자 계정 없이 동작한다.

## M6·M7 바릴로체 체험

바릴로체에서 미사포를 쓰고 촛불을 집어 들고 걷거나 앉은 뒤 촛대에 놓을 수 있다. 가까운 의자·촛대·고해소의 안내 버튼도 사용할 수 있다. 조명 메뉴에서 색유리 빛과 낮·해질녘·밤을 바꾸고 움직임과 효과를 줄일 수 있다. 고해소의 글은 바로 지워지며 추상적인 입자와 상승 시점으로 마무리한다. Esc로 연출을 건너뛸 수 있다.

성가대 버튼으로 제대 앞에 가서 감상하거나 66초 지휘 체험을 시작한다. 방향키 또는 화면 버튼을 음표에 맞춰 누른다. 본당의 가상 신자 스무 명은 열두 명이 앉고 여덟 명이 서 있으며 실제 접속자를 나타내지 않는다. 묵주는 아래로 당기거나 버튼·키보드로 한 알씩 넘긴다. 기념사진에서 현재 구도·정면 구도를 선택해 900×1100 PNG를 저장한다.

성가대의 「고요한 빛」은 이 프로젝트에서 제작한 합성 모음 합창이며 실제 성가대 녹음이 아니다. `python3 scripts/choir-audio.py`로 합창과 행동 효과음을 재생성한다. Python 표준 라이브러리와 ffmpeg가 필요하다. 레이스·석재·목재·빛 질감도 `src/sanctuary.ts`에서 직접 그린다. M8은 이전 오르간 배경음을 캐럴 녹음으로 교체했다.

`npm test`는 지휘 판정·재시작 및 촛불 스프라이트 자산 해제 회귀 테스트를 실행한다. M6·M7의 기능 확인 결과와 사람의 청취·분위기 평가 범위는 `docs/M6-verification.md`, `docs/M7-verification.md`에 기록했다.

## M8 성탄 분위기와 상세 색유리

바릴로체 뒤편 왼쪽에 높이 약 7m의 트리를 배치했다. 관람 지점의 「뒤편 크리스마스 트리」를 선택해 가까이 걸어갈 수 있다. 캐럴은 열 곡을 한 번씩 섞어 재생하며 순환 경계에서도 같은 곡을 연달아 고르지 않는다. 고해소·성가대 공연·페이지 비활성화 중에는 일시 정지한다. 개별 곡을 불러오지 못하면 다음 곡으로 넘기고, 모두 실패하면 재시도 안내를 표시한다.

색유리 창 15개(양측 12개·제대 뒤 3개)에 세 가지 창작 문양을 적용했다. 같은 창 이미지로 바닥 색빛을 만들고, 부드러운 빛줄기와 미세 먼지를 더했다. 낮·해질녘·밤에 강도를 바꾸며 밤에는 햇빛을 끈다. 움직임 줄이기는 먼지·트리·인물의 움직임을 멈춘다. 창작 이미지와 구현 방식은 `docs/stained-glass.md`, 검수는 `docs/M8-verification.md`를 참고한다. 이 변경은 바릴로체 체험에 적용되며 다른 아홉 성당의 건축을 일괄 수정하지 않는다.

## M9 신자와 빛 조정

가상 신자는20명이며 절반인10명이 미사포를 쓴다. 기존 빈 좌석 선택은 유지한다. 트리 전구100개에는 개별 밝기 변화와 후광을 적용하고, 본당 양쪽 벽기둥의 촛대12곳에 불꽃과 후광을 더했다. 움직임 줄이기에서는 일정한 밝기로 유지한다. 색유리는 원본 이미지를 수정하지 않고 렌더링 단계에서 채도를22% 줄이고 밝은 유리색을 약5.5% 섞었다. 짙은 납선은 보존하며 바닥 색빛에도 같은 보정을 적용한다.

## M10 트리 디테일

트리는 솔잎이 달린 입체 가지를 인스턴스 방식으로 촘촘히 배치한다. 장식96개, 전구180개와 더 넓은 후광, 발광하는 별과 별빛 반응을 적용했다. 전구는 각자 다른 시점에 강하게 빛나며 움직임 줄이기에서는 일정한 밝기로 유지한다.

## M11 오가는 방문자

기존 미사 관람 신자20명 외에 가상 방문자3명을 추가해 총23명이 머문다(성가대 별도). 방문자는 각자 예약된 좌석에서 쉬다가 성가대 앞에 다녀와 다시 앉고, 다음에는 고해소 입구에 다녀와 다시 앉는 순환을 서로 다른 간격으로 반복한다. 개인실과 사용자 글에는 접근하지 않는다. 사용자와 다른 인물 앞에서는 기다리거나 통로로 우회한다. 예약된 좌석은 사용자 착석 대상에서 제외한다. 효과 축소 또는 다른 활동 화면 중에는 이동을 멈춘다.

## M12 캐릭터·착석·출입문

재킷·베스트·롱코트·원피스·니트5종을 섞인 순서로 무작위 배치한다. 얼굴·머리·상의·신발 세부와 어깨·팔꿈치·고관절·무릎 관절을 추가했다. 사용자와 배경 인물, 이동 방문자는 같은 자세 제어를 사용한다. 걷기는 이동 속도에 따라 보폭·팔·무릎·몸의 작은 움직임이 연결된다. 착석 시 몸을 축소하는 방식을 제거하고 골반을 좌판 높이로 내려 무릎을 굽힌다. 일어난 후 걷기 전에는 짧은 전환 시간을 둔다.

본당 뒤벽 트리 옆에 석조 아치와 목재 양문으로 구성한 대형 출입문을 배치했다. 관람 지점에서 「대형 출입문」을 선택해 볼 수 있다. 건축 요소이며 외부 공간이나 계정 이동은 연결하지 않는다. `tests/avatar.test.mjs`는5종 모두의 골반·무릎·발 접촉과 부드러운 자세 전환을 검증한다.

## M13 헤어·기도 자세·강한 빛

옆가르마·단발·올린 웨이브·묶은 머리·곱슬머리5종을 의상과 독립적으로 섞는다. 앉은 신자6명은 눈을 감고 가슴 앞에 두 손을 모아 기도하며, 그중4명은 미사포를 쓴 신자다. 팔의 길이를 유지하는 관절 계산으로 손을 맞추고, 다른 자세에서는 눈과 팔을 복원한다.

오른쪽6개 창의 빛줄기·공중 먼지·바닥광을 강화했다. 트리에는 금빛·백색·옅은 청색의 별 섬광과 주변의 작은 빛 입자를 더했다. 밤에는 햇빛을 끄고 트리는 유지하며, 효과 축소에서는 움직임과 반짝임을 정적으로 유지한다.

## M14 연결된 기도와 공통 체험

첫 화면은 기도·앉기·마음 털어놓기·더 둘러보기로 정리했다. 추가 활동은 더 둘러보기 안에 모았다. 기도 여정은 촛불 켜기·놓기, 빈자리 착석, 합장과 눈 감기,30초/1분/3분 머무름,마침으로 이어진다. 단계 건너뛰기·시간 일시 정지·중단과 고해소 왕복을 지원한다. 바릴로체에서는 제대 앞 집전자와 기도12초·성가36초·마침12초의 창작 집전 장면도 볼 수 있다. 실제 미사나 성사를 제공하지 않는다.

임시 메뉴를 닫으면 이동 경로와 도착 행동이 이어진다. 지휘 화면은 전경 인물을 가리고 제대를 중심으로 보여준다. 인물·좌석에 접지 그림자를 더하고, 곱슬머리와 팔 연결을 보완했다. 나머지9개 성당은 각 공간에 맞춘 촛대·관람 지점과 기도 중인 방문자4명을 제공한다. 전용 트리·성가대·집전 연출은 바릴로체에서 제공한다.

즐겨찾기 성당·음량·효과음·조명·움직임 설정만 브라우저 저장소에 기억한다. 저장소가 차단되어도 체험은 계속된다. 개인실 글과 기도 기록은 저장하지 않는다.

## M15 기도 흐름과 공간 완성도

조용히 보기 중에도 기도 시간은 흐른다. 메뉴·비활성 탭·명시적 일시 정지는 계속 시간을 멈춘다. 착석 단계의 건너뛰기는 같은 자리에서 서서 기도하며, 이동 중에는 목적지·진행·예상 시간과 취소 버튼을 제공한다. 감상 시점은 앞자리 인물 위로 제대를 바라본다.

모든 성당에 닫힌 석재 볼트·리브, 벽 패널과 의자 디테일을 더했다.9개 성당에는 서로 다른 색유리 팔레트·문양·채광과 대표 장식을 보완했다. 집전 시점은 제대 전체를 담고, 인물 비율·옷감·관절 접합·집전복과 손동작을 조정했다. 햇살 먼지는 작고 옅은 원형으로 표현한다. 구현·검수 범위는 `docs/M15-verification.md`에 기록한다.

## M16 하단 빠른 메뉴

촛불 켜기·미사포 쓰기를 하단 기본 메뉴로 옮겼다. 작은 화면은 3열로 배치하며, 착석 후 조용히 보기까지 표시할 때 기도 안내와 겹치지 않도록 조정했다. [M16 검수](docs/M16-verification.md)를 참고한다.
