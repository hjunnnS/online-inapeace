# M16 · 하단 빠른 메뉴와 M15 재검수

## 관리와 승인
Milestone16, Epic #37의 실제 하위 Implementation #87(I078). 사용자 요청으로 촛불·미사포 메뉴 이동과 M15 재체험 검수를 승인받았다. 기존 이슈는 보존했다.

## 변경
촛불·미사포 버튼을 더 둘러보기에서 하단으로 이동했다. 버튼 ID·핸들러·효과·상태 표시는 그대로 재사용한다. 작은 화면은 3열 그리드, 넓은 화면은 줄바꿈 가능한 가로 메뉴다. 7번째 조용히 보기 버튼이 표시될 때 기도 안내가 메뉴와 겹치지 않도록 간격을 조정했다.

## 확인한 체험
- 공개 M15에서 미사포 착용 효과, 촛대로 이동·점화·놓기, 빈자리 이동·착석·일어나기, 조용히 보기 시점을 직접 확인했다.
- 고해소에서 검수용 문장을 입력하고 글 내려놓기로 본당에 복귀했다. 다시 열었을 때 입력란이 비어 있는 것을 화면에서 확인했다.
- 30초 기도에서 촛불·착석 단계를 건너뛰고 서서 기도했다. 조용히 보기에서 시간이 계속 흐르고 복귀 후 남은 시간이 감소했다.
- 로컬 수정본에서 미사포 착용/벗기 버튼 상태, 하단 촛불 켜기→촛불 놓기 전환과 실제 실행, 착석 후 조용히 보기 버튼 노출을 확인했다.
- 더 둘러보기에 촛불·미사포 중복이 없다. 집전 안내에서 제대 이동과 진행 표시를 확인했다.
- 1280×720, 390×844에서 메뉴를 확인했다. 작은 화면의 7개 버튼과 기도 안내가 서로 겹치지 않는다.
- 기존 자동 테스트 18개와 TypeScript·정적 빌드 통과. 번들 크기 안내(약772kB)는 남는다.

## 남은 품질 개선 후보 (이번에 추가 구현하지 않음)
1. 인물: 어깨·팔꿈치·무릎의 분절이 눈에 띄고 얼굴·의복 세부 표현이 단순하다. 미사포 반복 문양이 얼굴을 가리는 정도도 크다.
2. 재질·빛: 벽과 목재가 평면적으로 보이고 창의 채광 무늬는 근사 투영이다. 인물·가구의 접지감과 그림자 정합성이 부족하다.
3. 작은 화면: 착석 상태에서 버튼 7개가 3줄이 되어 화면을 많이 차지한다. 버튼을 직접 노출해 달라는 요청을 우선 반영했다. 기도 중에도 일반 행동과 여정 행동이 함께 보여 선택지가 많다.
4. 고해소: 실제 진입과 글 비우기는 동작하지만 주된 상호작용이 입력창 중심이다. 공간 안에서 머무는 몰입 연출은 더 보완할 수 있다.
5. 초기 로딩·실기기 성능: 큰 Three.js 번들 안내가 남는다. 실제 저사양 휴대전화의 발열·오디오 청감·장시간 체류는 이번 검증 범위가 아니다.

## 검증 한계
공개 M15 바릴로체와 수정본의 대표 기능 회귀 검수다. 10개 성당 전체를 이번에 재순회하거나 실제 미사·성사 체험을 검증한 것은 아니다. 물리 스피커의 소리를 들었다고 주장하지 않는다.
