# M14 · 연결된 기도 체험과 성당 공통 품질

사용자 승인: 2026-11-04 “업데이트 ㄱㄱ”. 기존 Epic #36·#37·#38을 재사용하고 실제 Milestone M14에 구현 Issue #71–#78을 연결했다. 기존 이슈의 내용과 승인 상태는 보존했다.

## 구현

- #71: 임시 메뉴는 입력만 비우고 경로·도착 행동을 보존한다. 다른 장면·고해소·입구·지휘로 전환하거나 새 목적지를 정하면 이전 이동을 취소한다.
- #72: 지휘 시점을 제대 중심으로 옮기고 플레이어와 카메라 앞의 배경 방문자를 가린다. 체험 종료 시 원래 노출을 복원한다.
- #73: 인물과 좌석에 저비용의 부드러운 접지 그림자를 추가했다. 곱슬머리를 작은 구슬 묶음에서 겹치는 머리 다발로 바꾸고 어깨·팔꿈치 접합을 보완했다. 모든 성당에 같은 석재·목재 재질 처리를 적용한다.
- #74: 바릴로체 제대에 집전자와 선택형 기도 12초·성가 36초·마침 12초 연출을 추가했다. 실제 미사나 성사를 대신하지 않는 창작 장면임을 안내한다.
- #75: 촛불 켜기·놓기 → 빈자리 착석 → 합장·감은 눈과 30초/1분/3분 머무름 → 마침으로 이어진다. 단계 건너뛰기, 일시 정지, 중단, 마음 털어놓기 왕복을 제공한다. 메뉴와 비활성 탭에서는 시간이 진행되지 않는다.
- #76: 첫 화면의 주요 행동은 기도·앉기·마음 털어놓기·더 둘러보기로 줄였다. 추가 활동은 마음/의례와 탐색/환경으로 묶었다.
- #77: 10개 성당에 촛불·미사포·착석·조용히 보기·조명·묵주·관람·사진·개인 기도를 제공한다. 나머지9곳은 각 장면 경계·좌석·입구를 기준으로 배치한다. 성가대·집전 장면·트리는 바릴로체 전용임을 명시한다.
- #78: 기기에 음량·효과음·조명·동작 줄이기·즐겨찾기 성당만 기억한다. 저장소가 차단되거나 데이터가 손상돼도 기본값으로 진입한다. 고해소 글·기도 내용·기도 기록·계정은 저장하지 않는다. 매일 바뀌는 짧은 묵상 문구는 로컬 문구7개를 순환한다.

## 실제 화면 검수

아래 결과는 IAB의 실제 버튼 조작과 화면/표시된 QA 상태를 기준으로 기록한다. 내부 상태를 직접 바꿔 통과시키지 않는다.

- 바릴로체 진입, 음악 재생 시간 증가, 음악 메뉴에서 음량 변경 확인.
- 제대까지 이동 중 음악 메뉴 열기 → 닫기 후 실제 위치가 (0,0,-10.7)에 도착. 기존 경로 취소 결함 재현 경로로 수정 확인.
- 성가대 지휘 진입: 전경 플레이어·방문자가 방향키 영역을 가리지 않는 화면 확인.
- 개인 기도: 촛불 점화·촛대에 놓기(placed=1, holding=false), 빈자리 착석과 합장·눈 감기 확인. 일시 정지 중 남은 시간 유지 확인.

- 개인 기도30초의 자동 마침까지 실제 대기하여 확인. 고해소 왕복 후 착석 단계로 복귀하고, 완료·취소 후 textarea가 빈 값임을 확인.
- 집전 장면은 기도 → 성가 → 마침 → 자동 종료를 실시간으로 확인. 음악·조명·사진 메뉴에서 장면 시간과 성가가 함께 멈추고 닫으면 이어짐을 확인. 메뉴가 시점을 지우던 추가 문제도 수정했다.
- 나머지9곳(파리·샤르트르·랭스·쾰른·밀라노·세비야·부르고스·성 비투스·성 슈테판)을 실제 목록에서 선택해 각 촛불 점화, 빈자리 착석, 고해소 진입과 본당 복귀를 확인했다. 파리·세비야·부르고스·성 비투스·성 슈테판에서는 개인 기도 진입·중단도 확인했다.
- 파리를 즐겨찾기로 지정하고 음량0.3·효과음0.15·밤 조명·효과 줄이기를 저장한 뒤 새로고침. 파리 진입 화면과 선택한 설정 복원을 확인했다. 이후 낮 조명과 일반 움직임으로 되돌렸다.
- 파리에서 조용히 보기 진입·복귀, 바릴로체에서 묵주 알 넘기기와 사진의 현재/정면 구도 생성 확인.
-390×844 뷰포트에서 주요 조작이 화면 범위 안에 배치되고 활동 메뉴가 표시됨을 확인한 후 기본 뷰포트로 복원했다. 실제 휴대전화 성능 검증과는 별개다.
-9개 장면 순회 후 브라우저 오류 로그0건. 바릴로체에서 다른 공간으로 바꿀 때 텍스처가45개에서 기본4개/촛불 체험15개로 줄었고, 이후 순회에서도15개 수준으로 유지됐다. 장시간 누수 부하 검증을 뜻하지 않는다.

## 범위와 한계

인물은 절차적 스타일의 모델이며 실사형 인물이나 모션 캡처가 아니다. 그림자는 접지용 근사 표현이며 창문을 통과한 실제 광선 추적 결과가 아니다. 다른9개 공간은 공식 자료를 참고한 부분 재구성이며 바릴로체와 같은 전용 장식·집전 장면을 제공하지 않는다. 실제 휴대전화의 발열·배터리와 물리 스피커의 청감은 별도 현장 확인이 필요하다.
