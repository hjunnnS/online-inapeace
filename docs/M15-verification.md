# M15 · 기도 흐름·감상 시점·공간 완성도 개선

사용자 승인: 공개 버전 직접 체험으로 정리한8개 개선사항에 대한 “진행해”. 실제 Milestone15와 기존 Epic #36·#37·#38의 하위 구현 Issue #79–#86으로 관리한다. 기존 이슈의 완료 상태와 내용은 보존했다.

## 구현 범위

- #79: 조용히 보기는 기도 시간과 분리했다. 메뉴·백그라운드·명시적인 일시 정지 중에는 시간이 멈추며, 조용히 보는 중에는 흐른다. 완료 후 조작 화면으로 돌아오면 마침 안내를 제공한다.
- #80: 조용히 보는 감상 시점을2.25m로 높이고 중앙 통로 쪽으로 조금 옮겨 앞자리 머리와 등받이 위로 제대가 보이게 한다. 이 시점을 위해 주변 인물을 일괄 제거하지 않는다.
- #81: 착석 단계의 “앉지 않고 여기서 기도”는 경로를 취소하고 같은 위치에서 서서 합장·눈 감기·기도 시간을 시작한다. 일반적인 빈자리 착석 선택은 유지한다.
- #82: 촛대·빈자리·고해소·제대·관람 지점에 목적지, 경로 진행과 남은 예상 시간, 이동 취소를 추가했다. 예상 시간은 경로 길이와 기본 보행 속도 기준이다. 임시 메뉴에서 경로는 보존한다.
- #83: 기존 검은 평지붕을 교체한 닫힌 석재 볼트, 대각 리브와 천장 줄눈, 하부 벽 패널·몰딩, 의자 끝 장식과 목재 레일, 개인실의 목재 패널·천장·쿠션·작은 등과 십자가를 보완했다. 새 장식은 기존 충돌 동선을 바꾸지 않는다. 석재와 목재는 월드 크기에 맞춰 질감을 배치한다.
- #84: 집전 카메라를 뒤로 물려 제대·집전자·성가대를 함께 보여준다. 인물의 머리 비율·눈·옷감·무릎·팔 접합을 조정하고, 집전복에 부드러운 주름과 점진적인 손동작을 더했다.5종 의상·헤어와 기존 관절 계산은 유지한다.
- #85: 햇살 먼지는180개에서96개로, 크기는0.035에서0.012로 줄이고 가장자리가 사라지는 원형 질감을 사용한다. 광선과 바닥광도 조금 낮췄다. 밤에는 햇살을 끄고 효과 줄이기에서는 움직이지 않는다.
- #86: 나머지9개 성당에 각각의 팔레트·꽃잎/별/랜싯 문양과 바닥 채광을 보완했다. 파리/랭스 장미창 트레이서리, 샤르트르 미로의 메달리온, 쾰른/세비야/슈테판의 성소 장식, 밀라노 대리석 바닥선, 부르고스 별 볼트, 성 비투스 측면 예배실 색채를 창작 장식으로 반영한다. 실측·스캔 재현을 뜻하지 않는다. 관람 지점에 “공간의 상징”을 더해 높은 창·별 볼트·미로·측면 예배실을 바라볼 수 있게 했다.

## 자동 검증

`npm test`:18개 통과. 기존 착석 접촉·자세 전환·기도 IK·자산 해제·지휘·캐럴 회귀와, 서서 기도하는5종 관절, 착석 건너뛰기, 시간 정지 조건, 목적지 취소 후 늦은 콜백 방지 검증. 기존 평지붕만 교체하고 바닥·벽·리브를 유지하는 기하 검증도 포함한다. 재질별로 합쳐진 모델에서도 지붕 삼각형만 교체하는 회귀를 검증한다.
`npm run build`: TypeScript 검사와 정적 빌드. Three.js 단일 번들 크기 안내는 남아 있다.

## 실제 화면 검수

IAB에서 실제 버튼을 조작하고 화면·표시된 QA 출력을 확인한다. 내부 상태를 강제로 바꿔 통과시키지 않는다.

- 바릴로체에서 촛불/착석 단계를 건너뛰어 위치(0,0,15), seated=false, navigating=false인 채 서서 기도하는 자세와 시간을 확인.
-30초 기도의 남은7초에서 조용히 보기 진입 후 마침까지 완료. 조작 화면 복귀 시 “기도 시간이 끝났습니다” 안내 확인.
- 수동 시간 정지와 음악 메뉴에서 남은60초 유지 확인.
- 고해소로 걷기 도중 진행 안내와 취소 확인. 취소 후 이전 개인실이 열리지 않고 새 빈자리 이동이 가능함을 확인.
- 제대 이동 도중 음악 메뉴에서 위치(-0.09,0,14.55)와 목적지가 유지되고, 닫은 뒤 진행이 이어짐을 확인.
- 우측 빈자리(2.97,0,8.19)에서 조용히 보기 진입. 앞자리 머리 위로 제대가 보이는 실제 화면 확인.
- 넓은 집전 시점과 성가 단계, 제대·집전자·성가대를 함께 담는 구도 확인.

- 나머지9개 성당을 실제 목록에서 선택해 각 공간의 서서 기도·촛불 점화·빈자리 착석·조용히 보기·개인실 진입/복귀를 확인했다. 각 성당의 새 창 문양·채광·건축 장식도 화면에서 확인했다.
- 파리에서 새 창 근접 관람과 낮/밤 전환, 개인실 글 내려놓기 후 textarea가 빈 값임을 확인했다.
- 부르고스 “공간의 상징”에서 위치(0,0,5)에 도착해 별 볼트와 닫힌 천장을 올려다보는 구도 확인.
- 장면 순회에서 다른 성당의 GPU 텍스처는 전체 시야가 열린 뒤 대체로22–24개 수준으로 유지됐다. 바릴로체의 인물·트리 자원을 해제한 후에는 텍스처 수가 줄었다. 장시간 부하 검증을 뜻하지 않는다.

- 바릴로체에서도 촛불 점화·촛대 놓기(placed=1)·착석·개인실 진입/복귀 확인. 전체10곳의 공통 동작을 순회했다.
- 파리 장미창, 성 비투스 측면 패널, 부르고스 별 볼트, 바릴로체 천장의 “공간의 상징” 관람 위치에 실제 도착하고 해당 구도를 확인했다.

- 실제 배포용 GLB10개도 별도로 읽어 기존 지붕의12개 삼각형(인덱스36개)만 제거됨을 확인했다. 바릴로체 근접 천장 관람에서 검은 띠와 아치 잘림이 해소된 화면을 확인했다.
-390×844 화면에서 관람 메뉴와 이동 안내·진행·취소 버튼이 화면 안에 배치됨을 확인하고 기본 뷰포트로 복원했다. 이동 안내 영역은 x=12–242, y=94–165 범위였다.
- 성당 순회와 최종 일반 화면의 브라우저 오류 로그0건.

## 범위와 한계

건축·인물은 절차적 스타일의 창작 부분 재구성이다. 실사 스캔이나 전문 인체 리깅/모션 캡처 수준의 모델을 제공하는 것은 아니다. 빛과 접지 그림자는 근사 표현이며 광선 추적 결과가 아니다. 실제 휴대전화의 발열·배터리와 물리 스피커의 청감은 별도 검증 대상이다. 고해소 글과 기도 기록은 저장하지 않는다.
